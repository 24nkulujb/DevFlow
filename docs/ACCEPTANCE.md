# 第一版验收清单

## 自动检查

- ./mvnw verify：H2 隔离数据库 + MockMvc。覆盖登录/退出、CSRF、项目隔离、创建校验、管理员边界、任务指派、版本冲突、跨项目任务/评论、移除成员、评论与统计。
- npm run check：不改代码的前端静态检查。
- npm run build：TypeScript 检查与生产构建。
- node scripts/smoke-test.mjs：真实 MySQL + HTTP + Cookie + CSRF，创建独立验收项目。不能代替浏览器交互验收。
- GitHub Actions 对 main 推送和 PR 自动运行后端 verify 与前端 check/build。

## 手动操作

1. 未登录访问项目地址，跳转登录；直接请求 API 返回401。
2. 错密码提示正确；正确登录显示当前用户；刷新保持会话；退出失效。
3. 项目创建、详情与管理员编辑；创建后刷新仍存在。
4. Alice 看不到 Bob 独立项目，猜项目/任务/评论 ID 也无权限。
5. 成员只能创建/查看项目任务与评论，不能管理成员或编辑项目。
6. 添加同用户第二次失败；不能移除自己；项目至少保留一名管理员。
7. 指派必须是项目成员，空标题及超长内容失败且表单保留输入。
8. 三列看板切换状态；筛选标题/状态/负责人/优先级/逾期；统计仍为整个项目。
9. 两页修改同任务，过期版本409，重新加载后可继续。
10. 移除成员，未完成任务清空负责人，完成任务保留历史负责人。
11. 评论非空且最多500字符，顺序正确，刷新保留。
12. 截止今天不算逾期；已完成不算逾期；空项目完成率0。
13. 手机宽度没有横向溢出，表单可用，抽屉可关闭；键盘 Escape 与焦点行为正常。
14. 服务中断显示错误，恢复可重试；不因刷新失败误导用户再次创建。
15. 已登录界面重启后端后会话失效，正确提示重新登录。

## 部署验证边界

当前本机没有 Docker，Compose/容器镜像配方没有进行实际容器运行验证。部署前先在目标机器运行 compose build/up，并重复此清单。
