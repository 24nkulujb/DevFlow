# 10 · 术语表与总复习

[目录](../LEARNING.md)

| 术语            | 普通语言解释                                         |
| --------------- | ---------------------------------------------------- |
| 全栈            | 同时理解浏览器、后端与数据库，不代表精通所有技术     |
| 框架/依赖       | 框架组织运行方式，依赖是工程使用的外部库             |
| API / interface | HTTP接口是调用约定；Java接口是类型能力声明，不同概念 |
| DTO             | 传输/接收数据的形状，限制客户端可写字段              |
| Bean/注入       | Spring管理对象，并把依赖传给需要的对象               |
| Mapper          | Java调用SQL的访问层                                  |
| 响应式          | Vue追踪数据变化并更新相关界面                        |
| props/emit      | 父传参数，子报告事件                                 |
| Promise         | 未来成功或失败的异步结果                             |
| JSON/序列化     | 数据文本格式；序列化将对象变传输格式                 |
| 主键/外键       | 唯一身份/引用存在的记录                              |
| 索引            | 加速定位记录的结构，也有维护成本                     |
| 事务            | 多个数据库操作整体提交或回滚                         |
| 竞态            | 并发交错导致结果依赖时序                             |
| 悲观锁/乐观锁   | 先锁再做 / 写入时验证旧版本                          |
| 认证/授权       | 你是谁 / 你可以做什么                                |
| Session/Cookie  | 后端会话状态 / 浏览器按规则保存发送的小数据          |
| CSRF            | 利用浏览器自动携带凭据的跨站写请求风险               |
| XSS             | 不可信脚本进入页面执行                               |
| 哈希            | 单向结果，密码哈希不能解密                           |
| Profile         | 选择运行配置/组件，例如demo/test/prod                |
| 迁移            | 版本化管理数据库结构变化                             |
| MockMvc         | 测试中模拟HTTP，不是浏览器自动化                     |
| 冒烟测试        | 快速验证主要路径，不是完整覆盖                       |
| CI              | 提交后自动检查流程                                   |
| 构建/部署       | 产出可运行文件 / 在目标环境运行服务                  |
| 代理            | 中间服务转发请求                                     |
| 持久化          | 数据进入长期存储，而非只在内存                       |
| 幂等            | 重复操作仍达到同一效果，普通新增POST未必如此         |

## 总复习答案

1. 前端显示Alice不能证明登录，因为状态能伪造/过期，后端会话才可信。
2. maxlength仍需DTO校验，因为用户可绕开表单直接请求。
3. 创建项目两条SQL是项目记录与管理员关系，必须整体成功。
4. 用户外键只保证用户存在，不保证属于任务所在项目。
5. task.version防过期写入；loadVersion/generation防过期响应改页面，不是一个概念。
6. 停止程序丢内存状态，不自动删已提交数据库。
7. 启动正常与API404不矛盾，服务在不代表每个地址/记录都有。
8. 写入超时可能只丢响应，重复提交可能新增两次。
9. 测试通过只覆盖已测场景，不保证所有生产风险消失。
10. 理解是能追完整调用链、解释失败和验证，并独立做小改动。
